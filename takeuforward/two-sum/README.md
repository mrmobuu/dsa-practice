# [Two Sum](https://takeuforward.org/practice/dsa/two-sum)

<p>Given an array of integers <strong>nums </strong>and an integer <strong>target</strong>. Return the indices(0 - indexed) of two elements in nums<strong> </strong>such that they add up to target.</p><p><br></p><p>Each input will have exactly one<strong> </strong>solution, and the same element <strong>cannot </strong>be used twice. Return<strong> </strong>the answer in any order.</p>

**Example 1**

<p><strong>Input</strong>: nums = [1, 6, 2, 10, 3], target = 7</p><p><strong>Output</strong>: [0, 1]</p><p><strong>Explanation</strong>: </p><p>nums[0] + nums[1] = 1 + 6 = 7</p>

**Example 2**

<p><strong>Input</strong>: nums = [1, 3, 5, -7, 6, -3], target = 0</p><p><strong>Output</strong>: [1, 5]</p><p><strong>Explanation</strong>:</p><p>nums[1] + nums[5] = 3 + (-3) = 0</p>

**Example 3**

<p><strong>Input</strong>: nums = [-6, 7, 1, -7, 6, 2], target = 3</p>

**Constraints**
