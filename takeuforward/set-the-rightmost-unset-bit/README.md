# [Set the Rightmost Unset Bit](https://takeuforward.org/practice/dsa/set-the-rightmost-unset-bit)

<p>You are given a positive integer n.</p><p>Your task is to set the rightmost unset bit (0 bit) in the binary representation of n.</p><p>Setting a bit means changing it from 0 to 1. Return the resulting integer after performing the operation.</p>

**Example 1**

<p><strong>Input:</strong> n = 10</p><p><strong>Output: </strong>11</p><p><strong>Explanation: </strong>10 is 1010 in binary. The rightmost 0 bit is set to 1, producing 1011, which is 11.</p>

**Example 2**

<p><strong>Input:</strong> n = 13</p><p><strong>Output:</strong> 15</p><p><strong>Explanation:</strong> 13 is 1101. Its rightmost unset bit is changed to 1: 1101 -&gt; 1111. Therefore, the result is 15.</p>

**Example 3**

<p><strong>Input:</strong> n = 8</p>

**Constraints**

<ul><li>1 &lt;= n &lt;= 10<sup>9</sup></li></ul>
