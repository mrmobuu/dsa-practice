# [Diameter of N-ary Tree](https://takeuforward.org/practice/dsa/diameter-of-n-ary-tree)

<p>Given the root of an N-ary tree, compute the length of its diameter.</p><p><br></p><p>The diameter is defined as the length of the longest path between any two nodes in the tree. (Nary-Tree input serialization is represented in their level order traversal, with each group of children separated by a null value.)</p>

**Example 1**

<p><img src="https://static.takeuforward.org/content/1789471388_xr_xPsmI.webp"></p><p><strong>Input:</strong> root = [1,null,3,2,4,null,5,6]</p><p><strong>Output:</strong> 3</p><p><strong>Explanation: </strong>The diameter of the N-ary tree is the longest path between any two nodes, which in this case is 3.</p>

**Example 2**

<p><img src="https://static.takeuforward.org/content/1789471396_uP6Ba_v-.webp"></p><p><strong>Input:</strong> root = [1,null,2,null,3,4,null,5,null,6]</p><p><strong>Output:</strong> 4</p><p><strong>Explanation:</strong> The diameter of the N-ary tree is the longest path between any two nodes, which in this case is 4.</p>

**Example 3**

<p><img src="https://static.takeuforward.org/content/1789471402_LMifETKR.webp"></p><p><strong>Input:</strong> root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]</p>

**Constraints**

<ul><li>The depth of the n-ary tree is less than or equal to 1000.</li><li>The total number of nodes is between [1, 10⁴].</li></ul>
