# [Largest rectangle in a histogram](https://takeuforward.org/practice/dsa/largest-rectangle-in-a-histogram)

<p>Given an array of integers heights representing the histogram's bar height where the width of each bar is 1&nbsp;return the area of the largest rectangle in the histogram.</p>

**Example 1**

<p>Input: heights = [2, 1, 5, 6, 2, 3]</p><p><br></p><p>Output: 10</p><p><br></p><p>Explanation: The largest rectangle is highlighted, which has an area of 5*2 = 10 units.</p><p><img src="https://static.takeuforward.org/content/1791829354_gHNn3_qo.webp"></p>

**Example 2**

<p>Input: heights = [3, 5, 1, 7, 5, 9]</p><p><br></p><p>Output: 15</p><p><br></p><p>Explanation: The largest rectangle has an area of 5*3 = 15 units.</p><p><img src="https://static.takeuforward.org/content/1791829379_WfZl0HIT.webp"></p>

**Example 3**

<p>Input: heights = [2,4]</p>

**Constraints**

<ul><li>&nbsp;&nbsp;1 &lt;= heights.length &lt;= 10<sup>5</sup></li><li>&nbsp;&nbsp;0 &lt;= heights[i] &lt;= 10<sup>4</sup></li></ul>
