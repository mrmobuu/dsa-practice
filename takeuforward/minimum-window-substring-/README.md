# [Minimum Window Substring ](https://takeuforward.org/practice/dsa/minimum-window-substring-)

<p>Given two strings s and t. Find the <strong>smallest</strong> window substring of s that includes all characters in t (including duplicates) , in the window. Return the empty string "" if no such substring exists.</p>

**Example 1**

<p><strong>Input :</strong> s = "ADOBECODEBANC" , t = "ABC"</p><p><strong>Output :</strong> "BANC"</p><p><strong>Explanation :</strong> The minimum window substring of string s that contains the string t is "BANC".</p>

**Example 2**

<p><strong>Input :</strong> s = "a" , t = "a"</p><p><strong>Output :</strong> "a"</p><p><strong>Explanation :</strong> The complete string is the minimum window</p>

**Example 3**

<p><strong>Input :</strong> s = "aAbBDdcC" , t = "Bc"</p>

**Constraints**

<ul><li>1 &lt;= n , m &lt;= 10<sup>5</sup></li><li>n = s.length</li><li>m = t.length</li><li>string s and t consist of uppercase and lowercase letters.</li></ul>
