# [Count the Number of Set Bits](https://takeuforward.org/practice/dsa/count-the-number-of-set-bits)

<p>Given an integer <strong>n</strong>, return the number of set bits (1s) in its binary representation.</p><p><br></p><p>Can you solve it in <strong>O(log n)</strong> time complexity?</p>

**Example 1**

<p><strong>Input:</strong> n = 5</p><p><strong>Output:</strong> 2</p><p><strong>Explanation:</strong> The binary representation of 5 is 101, which has 2 set bits.</p>

**Example 2**

<p><strong>Input:</strong> n = 15</p><p><strong>Output:</strong> 4</p><p><strong>Explanation: </strong>The binary representation of 15 is 1111, which has 4 set bits.</p>

**Example 3**

<p><strong>Input:</strong> n = 32</p>

**Constraints**

<ul><li>0 ≤ n ≤ 10⁹</li></ul>
