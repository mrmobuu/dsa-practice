# [Count Nodes in Linked List](https://takeuforward.org/practice/dsa/count-nodes-in-linked-list)

<p>Given the head of a singly linked list, return the <strong>number of nodes</strong> in the list.</p>

**Example 1**

<p><strong>Input:</strong> head = 1 -&gt; 2 -&gt; 3 -&gt; 4 -&gt; null</p><p><strong>Output:</strong> 4</p>

**Example 2**

<p><strong>Input:</strong> head = [1]</p><p><strong>Output:</strong> 1</p>

**Example 3**

<p><strong>Input:</strong> head = [1, 4]</p>

**Constraints**

<ul><li>1 &lt;= Number of Nodes &lt;= 10<sup>5</sup></li><li>Each node contains an integer value.</li></ul>
