# [Longest Consecutive Sequence in an Array](https://takeuforward.org/practice/dsa/longest-consecutive-sequence-in-an-array)

<p>Given an array nums of n integers.</p><p><br></p><p>Return the length of the <strong>longest sequence</strong> of consecutive integers. The integers in this sequence can appear in any order.</p>

**Example 1**

<p><strong>Input</strong>: nums = [100, 4, 200, 1, 3, 2]</p><p><strong>Output</strong>: 4</p><p><strong>Explanation</strong>: </p><p>The longest sequence of consecutive elements in the array is [1, 2, 3, 4], which has a length of 4. This sequence can be formed regardless of the initial order of the elements in the array.</p>

**Example 2**

<p><strong>Input</strong>: nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]</p><p><strong>Output</strong>: 9</p><p><strong>Explanation</strong>: </p><p>The longest sequence of consecutive elements in the array is [0, 1, 2, 3, 4, 5, 6, 7, 8], which has a length of 9.&nbsp;</p>

**Example 3**

<p><strong>Input</strong>: nums = [1, 9, 3, 10, 4, 20, 2]</p>

**Constraints**
