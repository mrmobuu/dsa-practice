# [Valid Anagram](https://takeuforward.org/practice/dsa/valid-anagram)

<p>Given two strings <strong>s</strong> and <strong>t</strong>, return <strong>true</strong> if t is an anagram of s, and <strong>false</strong> otherwise.</p><p><br></p><p>An <strong>Anagram</strong> is a word or phrase formed by rearranging the letters of a different word or phrase, typically using all the original letters exactly once.</p>

**Example 1**

<p><strong>Input :</strong> s = "anagram" , t = "nagaram"</p><p><strong>Output :</strong> true</p><p><strong>Explanation :</strong> </p><p>We can rearrange the characters of string s to get string t as frequency of all characters from both strings is same.</p>

**Example 2**

<p><strong>Input :</strong> s = "dog" , t = "cat"</p><p><strong>Output :</strong> false</p><p><strong>Explanation :</strong> </p><p>We cannot rearrange the characters of string s to get string t as frequency of all characters from both strings is not same.</p>

**Example 3**

<p><strong>Input :</strong> s = "eat" , t = "tea"</p>

**Constraints**

<ul><li>1 &lt;= s.length , t.length &lt;= 5*10<sup>4</sup></li><li>s and t consist of only lowercase English letters</li></ul>
