# [Top K Frequent Elements](https://takeuforward.org/practice/dsa/top-k-frequent-elements)

<p>Given an integer array nums and an integer <strong>k</strong>, return any order list of the k most frequent elements in nums.</p><p><br></p><p>Your solution must run in better than O(n log n) time, where <strong>n = nums.length</strong>.</p>

**Example 1**

<p><strong>Input:</strong>&nbsp;nums = [1,1,1,2,2,3],&nbsp;k = 2</p><p><strong>Output:</strong> [1,2]</p><p><strong>Explanation:</strong> 1 appears 3 times, 2 appears 2 times, 3 appears once.</p><p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;The two most-frequent elements are 1 and 2.</p>

**Example 2**

<p><strong>Input:&nbsp;</strong>nums = [4,4,6,6,7],&nbsp;k = 2</p><p><strong>Output:</strong> [4,6]</p><p><strong>Explanation:</strong> 4 and 6 both occur twice (highest), 7 occurs once.</p>

**Example 3**

<p><strong>Input:</strong>&nbsp;nums = [-1,-1,-2,-2,-2,-3],&nbsp;k = 1</p>

**Constraints**

<ul><li>1 ≤ nums.length ≤ 10<sup>5</sup></li><li>-10<sup>4</sup> ≤ nums[i] ≤ 10<sup>4</sup></li><li>1 ≤ k ≤ number of distinct elements in nums</li><li>The answer is guaranteed to be unique.</li></ul>
