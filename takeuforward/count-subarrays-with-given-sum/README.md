# [Count subarrays with given sum](https://takeuforward.org/practice/dsa/count-subarrays-with-given-sum)

<p>Given an array of integers nums and an integer k, return the total <strong>number of</strong> <strong>subarrays</strong> whose sum equals to k.</p>

**Example 1**

<p>Input: nums = [1, 1, 1], k = 2</p><p>Output: 2</p><p>Explanation: In the given array [1, 1, 1], there are two subarrays that sum up to 2: [1, 1] and [1, 1]. Hence, the output is 2.</p>

**Example 2**

<p>Input: nums = [1, 2, 3], k = 3</p><p>Output: 2</p><p>Explanation: In the given array [1, 2, 3], there are two subarrays that sum up to 3: [1, 2] and [3]. Hence, the output is 2.</p>

**Example 3**

<p>Input: nums = [3, 1, 2, 4], k = 6</p>
