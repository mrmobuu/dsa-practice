# [Sort Characters by Frequency](https://takeuforward.org/practice/dsa/sort-characters-by-frequency)

<p>You are given a string <strong>s</strong>. Return the array of <strong>unique</strong> characters, sorted by <strong>highest to lowest</strong> occurring characters.</p><p><br></p><p>If two or more characters have same frequency then arrange them in alphabetic order.</p>

**Example 1**

<p><strong>Input :</strong> s = "tree"</p><p><strong>Output :</strong> ['e', 'r', 't' ]</p><p><strong>Explanation :</strong> </p><p>The occurrences of each character are as shown below :</p><p>e --&gt; 2</p><p>r --&gt; 1</p><p>t --&gt; 1.</p><p>The r and t have same occurrences , so we arrange them by alphabetic order.</p>

**Example 2**

<p><strong>Input :</strong> s = "raaaajj"</p><p><strong>Output :</strong> ['a' , 'j', 'r' ]</p><p><strong>Explanation :</strong> </p><p>The occurrences of each character are as shown below :</p><p>a --&gt; 4</p><p>j --&gt; 2</p><p>r --&gt; 1</p>

**Example 3**

<p><strong>Input :</strong> s = "bbccddaaa"</p>

**Constraints**

<ul><li>1 &lt;= s.length &lt;= 10<sup>5</sup></li><li>s consist of only lowercase English characters.</li></ul>
