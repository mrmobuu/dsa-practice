# [Maximum Depth in BT](https://takeuforward.org/practice/dsa/maximum-depth-in-bt)

<p>Given root of the binary tree, return its <strong>maximum depth</strong>.</p><p>A binary tree's maximum depth is number of nodes along the longest path from root node down to the farthest node.</p>

**Example 1**

<p><strong>Input :</strong> root = [1, 2, 3, null, null, null , 6]</p><p><strong>Output :</strong> 3</p><p><strong>Explanation :</strong> The path from root node 1 to node with value 6 has maximum depth with 3 nodes along path.</p><p><br></p><p><img src="https://static.takeuforward.org/content/1789470317_UHqThEg9.webp"></p>

**Example 2**

<p><strong>Input :</strong> root = [3, 9, 20, null, null, 15 , 7]</p><p><strong>Output :</strong> 3</p><p><strong>Explanation :</strong> The path from root node 3 to node with value 15 has maximum depth with 3 nodes along path.</p><p>There exists other paths to reach the solution.</p><p><img src="https://static.takeuforward.org/content/1789470325_TYeGIuup.webp"></p>

**Example 3**

<p><strong>Input :</strong> root = [5, 1, 2, 8, null, null, 5, null, 4, null, null, 7]</p>

**Constraints**

<ul><li>1 &lt;= Number of Nodes &lt;= 10<sup>4</sup></li><li>0 &lt;= Node.val &lt;= 10<sup>4</sup></li></ul>
