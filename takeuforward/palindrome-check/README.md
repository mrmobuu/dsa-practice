# [Palindrome Check](https://takeuforward.org/practice/dsa/palindrome-check)

<p>You are given a string <strong>s</strong>. Return <strong>true</strong> if the string is palindrome, otherwise <strong>false</strong>. </p><p><br></p><p>A string is called <strong>palindrome</strong> if it reads the same forward and backward.</p>

**Example 1**

<p><strong>Input :</strong> s = "hannah"</p><p><strong>Output :</strong> true</p><p><strong>Explanation :</strong> </p><p>The given string when read backward is -&gt; "hannah", which is same as when read forward.</p><p>Hence answer is true.</p>

**Example 2**

<p><strong>Input :</strong> s = "aabbaaa"</p><p><strong>Output :</strong> false</p><p><strong>Explanation :</strong> </p><p>The given string when read backward is -&gt; "aaabbaa", which is not same as when read forward.</p><p>Hence answer is false.</p>

**Example 3**

<p><strong>Input :</strong> s = "aabbccbbaa"</p>

**Constraints**

<ul><li>1 &lt;= s.length &lt;= 10<sup>5</sup></li><li>s consist of only uppercase and lowercase English characters.</li></ul>
