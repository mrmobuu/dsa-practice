# [Print all primes till N](https://takeuforward.org/practice/dsa/print-all-primes-till-n)

<p>You are given an integer <strong>n</strong>.</p><p>Print all the prime numbers till n (including n).</p><p>A <strong>prime number</strong> is a number that has only two divisor's 1 and the number itself.</p>

**Example 1**

<p><strong>Input :</strong> n = 7</p><p><strong>Output :</strong> [2, 3, 5, 7]</p><p><strong>Explanation :</strong> The number 2 has only two divisors 1 and 2.</p><p>The number 3 has only two divisors 1 and 3.</p><p>The number 5 has only two divisors 1 and 5.</p><p>The number 7 has only two divisors 1 and 7.</p>

**Example 2**

<p><strong>Input :</strong> n = 2</p><p><strong>Output :</strong> [2]</p><p><strong>Explanation :</strong> There is only one number 2 that is a prime till 2.</p>

**Example 3**

<p><strong>Input :</strong> n = 10</p>

**Constraints**

<ul><li>2 &lt;= n &lt;= 5*10<sup>5</sup></li></ul>
