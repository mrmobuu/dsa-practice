# [Longest Substring Without Repeating Characters](https://takeuforward.org/practice/dsa/longest-substring-without-repeating-characters)

<p>Given a string, S. Find the <strong>length</strong> of the longest substring without repeating characters.</p>

**Example 1**

<p><strong>Input :</strong> S = "abcddabac"</p><p><strong>Output :</strong> 4</p><p><strong>Explanation :</strong> The answer is "abcd" , with a length of 4.</p>

**Example 2**

<p><strong>Input :</strong> S = "aaabbbccc"</p><p><strong>Output :</strong> 2</p><p><strong>Explanation :</strong> The answers are "ab" , "bc". Both have maximum length 2.</p>

**Example 3**

<p><strong>Input :</strong> S = "aaaa"</p>

**Constraints**

<ul><li>1 &lt;= S.length &lt;= 5*10<sup>4</sup></li><li>S contains only English lowercase letters.</li></ul>
