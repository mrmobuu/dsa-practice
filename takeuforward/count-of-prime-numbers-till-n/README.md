# [Count of Prime Numbers till N](https://takeuforward.org/practice/dsa/count-of-prime-numbers-till-n)

<p>You are given an integer <strong>n</strong>. You need to find out the <strong>number </strong>of <strong>prime </strong>numbers in the range<strong> [1, n] </strong>(inclusive). Return the <strong>number </strong>of <strong>prime </strong>numbers in the range.</p><p><br></p><p>A <strong>prime </strong>number is a number which has <strong>no </strong>divisors except, <strong>1 </strong>and <strong>itself</strong>.</p>

**Example 1**

<p><strong>Input</strong>: n = 6</p><p><strong>Output</strong>: 3</p><p><strong>Explanation</strong>: Prime numbers in the range [1, 6] are 2, 3, 5.</p>

**Example 2**

<p><strong>Input</strong>: n = 10</p><p><strong>Output</strong>: 4</p><p><strong>Explanation</strong>: Prime numbers in the range [1, 10] are 2, 3, 5, 7.</p>

**Example 3**

<p><strong>Input</strong>: n = 20</p>

**Constraints**

<ul><li>2 &lt;= n &lt;= 1000</li></ul>
