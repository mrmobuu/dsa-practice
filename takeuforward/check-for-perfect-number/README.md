# [Check for Perfect Number](https://takeuforward.org/practice/dsa/check-for-perfect-number)

<p>You are given an integer<strong> n</strong>. You need to check if the number is a <strong>perfect </strong>number or not. Return <strong>true </strong>if it is a <strong>perfect </strong>number, otherwise, return <strong>false</strong>.</p><p><br></p><p>A <strong>perfect </strong>number is a number whose proper <strong>divisors </strong>(excluding the number itself)<strong> </strong>add up to the number <strong>itself</strong>.</p>

**Example 1**

<p><strong>Input</strong>: n = 6</p><p><strong>Output</strong>: true</p><p><strong>Explanation</strong>: Proper divisors of 6 are 1, 2, 3.</p><p>1 + 2 + 3 = 6.</p>

**Example 2**

<p><strong>Input</strong>: n = 4</p><p><strong>Output</strong>: false</p><p><strong>Explanation</strong>: Proper divisors of 4 are 1, 2.</p><p>1 + 2 = 3.</p>

**Example 3**

<p><strong>Input</strong>: n = 28</p>

**Constraints**

<ul><li>1 &lt;= n &lt;= 5000</li></ul>
