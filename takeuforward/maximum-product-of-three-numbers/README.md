# [Maximum Product of Three Numbers](https://takeuforward.org/practice/dsa/maximum-product-of-three-numbers)

<p>Given an integer array nums, find three numbers whose product is maximum and return the maximum product.</p>

**Example 1**

<p><strong>Input: </strong>nums = [1, 2, 3]</p><p><strong>Output:</strong> 6</p><p><strong>Explanation:</strong> 1 × 2 × 3 = 6</p>

**Example 2**

<p><strong>Input: </strong>nums = [1, 2, 3, 4]</p><p><strong>Output:</strong> 24</p><p><strong>Explanation:</strong> 2 × 3 × 4 = 24</p>

<p><strong>Input:</strong> nums = [-1, -2, -3]</p><p><br></p>
