# [Single Number - I](https://takeuforward.org/practice/dsa/single-number---i)

<p>Given an array of nums of n integers. Every integer in the array appears twice except one integer. Find the number that appeared <strong>once</strong> in the array.</p>

**Example 1**

<p><strong>Input :</strong> nums = [1, 2, 2, 4, 3, 1, 4]</p><p><strong>Output :</strong> 3</p><p><strong>Explanation :</strong> The integer 3 has appeared only once.</p>

**Example 2**

<p><strong>Input :</strong> nums = [5]</p><p><strong>Output :</strong> 5</p><p><strong>Explanation :</strong> The integer 5 has appeared only once.</p>

**Example 3**

<p><strong>Input :</strong> nums = [1, 3, 10, 3, 5, 1, 5]</p>

**Constraints**

<ul><li>1 &lt;= n &lt;= 10<sup>5</sup></li><li>-3*10<sup>5</sup> &lt;= nums[i] &lt;= 3*10<sup>5</sup></li></ul>
