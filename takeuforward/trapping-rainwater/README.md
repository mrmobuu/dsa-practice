# [Trapping Rainwater](https://takeuforward.org/practice/dsa/trapping-rainwater)

<p>Given an array of non-negative integers, <strong>height</strong> representing the elevation of ground. Calculate the <strong>amount</strong> of water that can be trapped after rain.</p>

**Example 1**

<p>Input: height= [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]</p><p>Output: 6</p><p>Explanation: As seen from the diagram 1+1+2+1+1=6 unit of water can be trapped</p><p><br></p><p><img src="https://static.takeuforward.org/content/1789481863_WyL4xpuo.webp"></p>

**Example 2**

<p>Input: height= [4, 2, 0, 3, 2, 5]</p><p>Output: 9</p><p>Expalanation: 2+4+1+2=9 unit of water can be trapped</p>

**Example 3**

<p>Input: height= [7, 4, 0, 9]</p>

**Constraints**

<ul><li>&nbsp;&nbsp;n == height.length</li><li>&nbsp;&nbsp;1 &lt;= n &lt;= 10<sup>5</sup></li><li>&nbsp;&nbsp;0 &lt;= height[i] &lt;= 10<sup>5</sup></li></ul>
