# [Find missing number](https://takeuforward.org/practice/dsa/find-missing-number)

<p>Given an integer array of size n containing distinct values in the range from <strong>0 to n (inclusive)</strong>, return the only number missing from the array within this range.</p>

**Example 1**

<p><strong>Input</strong>: nums = [0, 2, 3, 1, 4]</p><p><strong>Output</strong>: 5</p><p><strong>Explanation</strong>: </p><p>nums contains 0, 1, 2, 3, 4 thus leaving 5 as the only missing number in the range [0, 5]</p>

**Example 2**

<p><strong>Input</strong>: nums = [0, 1, 2, 4, 5, 6]</p><p><strong>Output</strong>: 3</p><p><strong>Explanation</strong>: </p><p>nums contains 0, 1, 2, 4, 5, 6 thus leaving 3 as the only missing number in the range [0, 6]</p>

**Example 3**

<p><strong>Input</strong>: nums = [1, 3, 6, 4, 2, 5]</p>

**Constraints**

<ul><li>n == nums.length</li><li>1 &lt;= n &lt;= 10<sup>4</sup></li><li>0 &lt;= nums[i] &lt;= n</li><li>All the numbers of nums are unique.</li></ul>
