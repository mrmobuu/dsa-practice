# [Find the Duplicate Number](https://takeuforward.org/practice/dsa/find-the-duplicate-number)

<p>Given an array of integers nums containing n + 1 integers where each integer is in the range [1, n] inclusive, there is only one repeated number in nums (but can repeated more than once), return this duplicate number.</p><p><br></p><p>You must not modify the array (assume it is read-only), and you must use only constant extra space.</p><p><br></p><p>Your algorithm should run in less than O(n²) time.</p>

**Example 1**

<p><strong>Input:</strong> nums = [1,3,4,2,2]</p><p><strong>Output</strong>: 2</p>

**Example 2**

<p><strong>Input: </strong>nums = [3,1,3,4,2]</p><p><strong>Output:</strong> 3</p>

**Example 3**

<p><strong>Input:</strong> nums = [1,1]</p>

**Constraints**

<ul><li>1 &lt;= n &lt;= 10<sup>5</sup></li><li>nums.length == n + 1</li><li>1 &lt;= nums[i] &lt;= n</li><li>Only one duplicate number, but it can be repeated more than once</li></ul>
