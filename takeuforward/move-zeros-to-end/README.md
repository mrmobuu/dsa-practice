# [Move Zeros to End](https://takeuforward.org/practice/dsa/move-zeros-to-end)

<p>Given an integer array <strong>nums</strong>, move all the 0's to the end of the array. The relative order of the other elements must remain the same. </p><p><br></p><p>This must be done in place, without making a copy of the array.</p>

**Example 1**

<p><strong>Input</strong>: nums = [0, 1, 4, 0, 5, 2]</p><p><strong>Output</strong>: [1, 4, 5, 2, 0, 0]</p><p><strong>Explanation</strong>: </p><p>Both the zeroes are moved to the end and the order of the other elements stay the same</p>

**Example 2**

<p><strong>Input</strong>: nums = [0, 0, 0, 1, 3, -2]</p><p><strong>Output</strong>: [1, 3, -2, 0, 0, 0]</p><p><strong>Explanation</strong>: </p><p>All 3 zeroes are moved to the end and the order of the other elements stay the same</p>

**Example 3**

<p><strong>Input</strong>: nums = [0, 20, 0, -20, 0, 20]</p>

**Constraints**

<ul><li>1 &lt;= nums.length &lt;= 10<sup>5</sup></li><li>-10<sup>4</sup> &lt;=nums[i] &lt;= 10<sup>4</sup></li></ul>
