# [Palindrome Number](https://takeuforward.org/practice/dsa/palindrome-number)

<p>You are given an integer <strong>n</strong>. You need to check whether the number is a <strong>palindrome </strong>number or not. Return <strong>true </strong>if it's a <strong>palindrome </strong>number, otherwise return <strong>false</strong>.</p><p><br></p><p>A <strong>palindrome </strong>number is a number which reads the <strong>same </strong>both <strong>left to right</strong> and <strong>right to left</strong>.</p>

**Example 1**

<p><strong>Input</strong>: n = 121</p><p><strong>Output</strong>: true</p><p><strong>Explanation</strong>: When read from left to right : 121.</p><p>When read from right to left : 121.</p>

**Example 2**

<p><strong>Input</strong>: n = 123</p><p><strong>Output</strong>: false</p><p><strong>Explanation</strong>: When read from left to right : 123.</p><p>When read from right to left : 321.</p>

**Example 3**

<p>Input: 101</p>

**Constraints**

<ul><li>0 &lt;= n &lt;= 5000</li><li>n will contain no leading zeroes except when it is 0 itself.</li></ul>
