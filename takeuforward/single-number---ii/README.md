# [Single Number - II](https://takeuforward.org/practice/dsa/single-number---ii)

<p>Given an array nums where each integer in nums appears <strong>thrice </strong>except one. Find out the number that has appeared only <strong>once</strong>.</p>

**Example 1**

<p><strong>Input :</strong> nums = [2, 2, 2, 3]</p><p><strong>Output :</strong> 3</p><p><strong>Explanation :</strong> The integers 3 has appeared only once.</p>

**Example 2**

<p><strong>Input :</strong> nums = [1, 0, 3, 0, 1, 1, 3, 3, 10, 0]</p><p><strong>Output :</strong> 10</p><p><strong>Explanation :</strong> The integers 10 has appeared only once.</p>

**Example 3**

<p><strong>Input :</strong> nums = [5, 0, 1, 10, 1, 1, 5, 5, 10, 10]</p>

**Constraints**

<ul><li>1 &lt;= n &lt;= 3*10<sup>4</sup></li><li>-2<sup>31</sup> &lt;= nums[i] &lt;= 2<sup>31</sup> - 1</li></ul>
