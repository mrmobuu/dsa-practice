# [Majority Element-II](https://takeuforward.org/practice/dsa/majority-element-ii)

<p>Given an <strong>integer </strong>array <strong>nums </strong>of size <strong><em>n</em></strong>. Return <strong>all </strong>elements which <strong>appear more than</strong> <strong>n/3</strong> times in the array. The output can be returned in <strong>any </strong>order.</p>

**Example 1**

<p><strong>Input</strong>: nums = [1, 2, 1, 1, 3, 2]</p><p><strong>Output</strong>: [1]</p><p><strong>Explanation</strong>: </p><p>Here, n / 3 = 6 / 3 = 2.</p><p>Therefore the elements appearing 3 or more times is : [1]</p>

**Example 2**

<p><strong>Input</strong>: nums = [1, 2, 1, 1, 3, 2, 2]</p><p><strong>Output</strong>: [1, 2]</p><p><strong>Explanation</strong>: </p><p>Here, n / 3 = 7 / 3 = 2.</p><p>Therefore the elements appearing 3 or more times is : [1, 2]</p>

**Example 3**

<p><strong>Input</strong>: nums = [1, 2, 1, 1, 3, 2, 2, 3](Give the solution sorted in ascending order)</p>

**Constraints**

<ul><li>n == nums.length.</li><li>2 &lt;= n &lt;= 10<sup>5</sup></li><li>-10<sup>4</sup> &lt;= nums[i] &lt;= 10<sup>4</sup></li></ul>
