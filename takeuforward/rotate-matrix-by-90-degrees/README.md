# [Rotate matrix by 90 degrees](https://takeuforward.org/practice/dsa/rotate-matrix-by-90-degrees)

<p>Given an N * N 2D integer matrix, rotate the matrix by 90 degrees clockwise.</p><p><br></p><p>The rotation must be done in place, meaning the input 2D matrix must be modified directly.</p>

**Example 1**

<p><strong>Input</strong>: matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]</p><p><br></p><p><img src="https://static.takeuforward.org/content/1789410972_Ys-H_F6b.webp"></p><p><br></p><p><br></p><p><strong>Output</strong>: matrix = [[7, 4, 1], [8, 5, 2], [9, 6, 3]]</p><p><br></p><p><img src="https://static.takeuforward.org/content/1789456262_JTPopmQZ.webp"></p>

**Example 2**

<p><strong>Input</strong>: matrix = [[0, 1, 1, 2], [2, 0, 3, 1], [4, 5, 0, 5], [5, 6, 7, 0]]</p><p><br></p><p><img src="https://static.takeuforward.org/content/1789456273_nwEzmDt8.webp"></p><p><br></p><p><strong>Output</strong>: matrix = [[5, 4, 2, 0],&nbsp;[6, 5, 0, 1], [7, 0, 3, 1], [0, 5, 1, 2]]</p><p><br></p><p><img src="https://static.takeuforward.org/content/1789456282_20u3h9-R.webp"></p>

**Example 3**

<p><strong>Input</strong>: matrix = [[1, 1, 2], [5, 3, 1], [5, 3, 5]]</p>

**Constraints**

<ul><li>n == matrix.length.</li><li>n == matrix[i].length.</li><li>1 &lt;= n &lt;= 100.</li><li>-10<sup>4</sup> &lt;= matrix[i][j] &lt;= 10<sup>4</sup></li></ul>
