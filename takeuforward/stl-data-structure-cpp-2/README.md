# [Map Store](https://takeuforward.org/practice/dsa/stl-data-structure-cpp-2)

<p>You are given:</p><ul><li>An integer n representing number of students</li><li>Two arrays:</li><li class="ql-indent-1">roll[] → roll numbers</li><li class="ql-indent-1">marks[] → corresponding marks</li></ul><p><br></p><p>Store the data using a map such that:</p><ul><li>Key = roll number (integer)</li><li>Value = marks (integer)</li></ul><p>Return the map.</p>

**Example 1**

<p><strong>Input</strong>: roll = [3, 1, 2], marks = [80, 90, 85]</p><p><strong>Output</strong>:</p><p>1 90</p><p>2 85</p><p>3 80</p>

**Example 2**

<p><strong>Input</strong>: roll = [5, 6], marks = [-5, 0]</p><p><strong>Output</strong>:</p><p>5 -5</p><p>6 0</p>

**Constraints**

<ul><li>1 &lt;= roll.size() == marks.size() &lt;= 100</li><li>1 &lt;= roll[i] &lt;= 100</li><li>-100 &lt;= marks[i] &lt;= 100</li></ul>
