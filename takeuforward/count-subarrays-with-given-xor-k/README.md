# [Count subarrays with given xor K](https://takeuforward.org/practice/dsa/count-subarrays-with-given-xor-k)

<p>Given an array of integers nums and an integer k, return the total number of subarrays whose <strong>XOR</strong> equals to k.</p>

**Example 1**

<p>Input : nums = [4, 2, 2, 6, 4], k = 6</p><p><br></p><p>Output : 4</p><p><br></p><p>Explanation : The subarrays having XOR of&nbsp;their elements as 6 are [4, 2],&nbsp;&nbsp;[4, 2, 2, 6, 4], [2, 2, 6], and [6]</p>

**Example 2**

<p>Input :nums = [5, 6, 7, 8, 9], k = 5</p><p><br></p><p>Output : 2</p><p><br></p><p>Explanation : The subarrays having XOR of&nbsp;their elements as 5 are [5] and [5, 6, 7, 8, 9]</p>

**Example 3**

<p>Input : nums = [5, 2, 9], k = 7</p>

**Constraints**

<ul><li>&nbsp;&nbsp;1 &lt;= nums.length &lt;=&nbsp;10<sup>5</sup></li><li>&nbsp;&nbsp;1 &lt;= nums[i] &lt;= 10<sup>9</sup></li><li>&nbsp;&nbsp;1 &lt;= k &lt;= 10<sup>9</sup></li></ul>
