# [Majority Element-I](https://takeuforward.org/practice/dsa/majority-element-i)

<p>Given an integer array <strong>nums</strong> of size <strong>n</strong>, return the majority element of the array.</p><p><br></p><p>The majority element of an array is an element that appears more than n/2 times in the array. The array is guaranteed to have a majority element.</p>

**Example 1**

<p><strong>Input</strong>: nums = [7, 0, 0, 1, 7, 7, 2, 7, 7]</p><p><strong>Output</strong>: 7</p><p><strong>Explanation</strong>: </p><p>The number 7 appears 5 times in the 9 sized array</p>

**Example 2**

<p><strong>Input</strong>: nums = [1, 1, 1, 2, 1, 2]</p><p><strong>Output</strong>: 1</p><p><strong>Explanation</strong>: </p><p>The number 1 appears 4 times in the 6 sized array</p>

**Example 3**

<p><strong>Input</strong>: nums = [-1, -1, -1, -1]</p>

**Constraints**

<ul><li>n == nums.length.</li><li>1 &lt;= n &lt;= 10<sup>5</sup></li><li>-10<sup>4</sup> &lt;= nums[i] &lt;= 10<sup>4</sup></li><li>One value appears more than n/2 times.</li></ul>
