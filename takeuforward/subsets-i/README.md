# [Subsets I](https://takeuforward.org/practice/dsa/subsets-i)

<p>Given an array nums of n integers. Return array of <strong>sum</strong> of all subsets of the array nums.</p><p><br></p><p>Output can be returned in any order.</p>

**Example 1**

<p><strong>Input : </strong>nums = [2, 3]</p><p><strong>Output : </strong>[0, 2, 3, 5]</p><p><strong>Explanation : </strong></p><p>When no elements is taken then Sum = 0.</p><p>When only 2 is taken then Sum = 2.</p><p>When only 3 is taken then Sum = 3.</p><p>When element 2 and 3 are taken then&nbsp;sum = 2+3 = 5.</p>

**Example 2**

<p><strong>Input :</strong> nums = [5, 2, 1]</p><p><strong>Output :</strong> [0, 1, 2, 3, 5, 6, 7, 8]</p><p><strong>Explanation :</strong></p><p>When no elements is taken then Sum = 0.</p><p>When only 5 is taken then Sum = 5.</p><p>When only 2 is taken then Sum = 2.</p><p>When only 1 is taken then Sum = 1.</p><p>When element 2 and 1 are taken then&nbsp;sum = 2+1 = 3.</p>

**Example 3**

<p><strong>Input :</strong> nums = [1]</p>

**Constraints**

<ul><li>1 &lt;= n &lt;= 15</li><li>0 &lt;= nums[i] &lt;= 10<sup>4</sup></li></ul>
