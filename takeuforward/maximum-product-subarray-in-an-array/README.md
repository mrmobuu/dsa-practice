# [Maximum Product Subarray in an Array](https://takeuforward.org/practice/dsa/maximum-product-subarray-in-an-array)

<p>Given an integer array <strong>nums</strong>. Find the <strong>subarray </strong>with the <strong>largest product</strong>, and return the <strong>product </strong>of the elements present in that <strong>subarray</strong>.</p><p><br></p><p>A <strong>subarray </strong>is a <strong>contiguous </strong>non-empty <strong>sequence </strong>of elements within an array.</p>

**Example 1**

<p><strong>Input</strong>: nums = [4, 5, 3, 7, 1, 2]</p><p><strong>Output</strong>: 840</p><p><strong>Explanation</strong>: </p><p>The largest product is given by the whole array itself</p>

**Example 2**

<p><strong>Input</strong>: nums = [-5, 0, -2]</p><p><strong>Output</strong>: 0</p><p><strong>Explanation</strong>: </p><p>The largest product is achieved with the following subarrays [0], [-5, 0], [0, -2], [-5, 0, -2].</p>

**Example 3**

<p><strong>Input</strong>: nums = [1, -2, 3, 4, -4, -3]</p>

**Constraints**

<ul><li>1 &lt;= nums.length &lt;= 10<sup>4</sup></li><li>-10 &lt;= nums[i] &lt;= 10</li><li>-10<sup>9</sup> &lt;= product of any prefix or suffix of nums &lt;= 10<sup>9</sup></li></ul>
