# [Balanced Paranthesis](https://takeuforward.org/practice/dsa/balanced-paranthesis)

<p>Given string <strong>str</strong> containing just the characters '(', ')', '{', '}', '[' and ']', check if the input string is valid and return true if the string is balanced otherwise return false.</p>

**Example 1**

<p>Input: str = “()[{}()]”</p><p>Output: True</p><p>Explanation: As every open bracket has its corresponding&nbsp;close bracket. Match parentheses are in correct order&nbsp;hence they are balanced.</p>

**Example 2**

<p>Input: str = “[()”</p><p>Output: False</p><p>Explanation: As ‘[‘ does not have ‘]’ hence it is&nbsp;not valid and will return false.</p>

**Example 3**

<p>Input: str = "{[()]}"</p>

**Constraints**

<p>1 &lt;= str.length &lt;= 10<sup>4</sup></p><p>str consists of parentheses only '()[]{}'.</p>
